# Görseller

Tüm görseller `scripts/fetch_images.py` ile indirilir; atıf, lisans ve kaynak linki `data/gorseller.json` içinde tutulur ve sitede her görselin altında gösterilir.

- Dünya mağaraları: Wikimedia Commons (CC BY / CC BY-SA / CC0 / kamu malı; NPS ve USGS görselleri kamu malı).
- Ay çukurları: NASA/GSFC/Arizona State University (LROC), kamu malı.
- Mars: Arsia skylight'ları NASA/JPL/USGS/ASU/NAU (THEMIS), kamu malı; diğerleri HiRISE, kamu malı (NASA/JPL/University of Arizona).

CC BY-SA görselleri değiştirilmeden, yalnız küçültülerek kullanılmıştır. Yeni görsel eklerken atıf bilgisini `data/gorseller.json`'a yazın.
